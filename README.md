# Todo List

Простое -приложение Мои задачи на чистом HTML, CSS и JavaScript. Учебный проект по вайб-кодингу.

## 🌐 Демо

[Открыть приложение](https://celebrated-panda-fe17f9.netlify.app)

## ✨ Функции

- ✅ Добавление задач (Enter или кнопка)
- ✅ Удаление отдельных задач
- ✅ Отметка выполненных (зачёркивание текста)
- ✅ Фильтр: Все / Активные / Выполненные
- ✅ Счётчик: «Активных: X | Выполнено: Y из Z»
- ✅ Кнопка «Очистить выполненные»
- ✅ Сохранение в localStorage — задачи не пропадают после перезагрузки
- ✅ Тёмная тема
- ✅ Адаптивность для мобильных

## 🛠 Стек

- **HTML5** — семантическая вёрстка
- **CSS3** — flex, тёмная тема
- **Vanilla JavaScript** — без фреймворков
- **localStorage** — сохранение данных

## 🚀 Как запустить локально

1. Скачайте папку проекта
2. Откройте `index.html` в браузере
3. Или используйте **Live Server** в VS Code
